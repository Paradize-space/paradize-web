# Paradize

**A home for people who build hardware.**

Document hardware projects, version the hardware and software together, check
what you already have, and source what you still need.

**[paradize.space](https://paradize.space)** · Paradize is pre-launch.
[Join the waitlist](https://paradize.space/#early-access).

## The problem

Most hardware projects die in the gap between finding one and building it.

Files drift. Instructions go stale. The board someone photographed two years
ago is on its third revision, and nobody wrote down which one the photographs
belong to.

Paradize closes that gap. A project is written down once and published as
releases, so the version someone builds is a version that was really shipped.

## Three streams, built together

- **[Platform](https://paradize.space/#platform)**: profiles, project docs,
  hardware and firmware releases, builds that know your parts bin.
- **[Marketplace](https://paradize.space/marketplace)**: components and kits,
  tied to the release you are building.
- **[Research](https://paradize.space/research)**: work by the team inside
  Paradize.

## From a published project to a finished build

Five steps, end to end. None of it is live yet; this is the shape of what we
are building.

1. **Project.** Write the project down once. One project holds the design, the
   build instructions, the parts list and the firmware that goes with them.
2. **Releases.** Publish a release each time it changes. A release pins one
   snapshot: board revision, firmware, parts list, instructions. The project
   can move on without breaking the build someone started last month.
3. **Build.** Someone else builds that exact version. They build a published
   release. One release, one set of instructions, one unit that matches it.
4. **Inventory.** Check it against the parts you own. Your inventory knows the
   difference between free and already committed. A part sitting inside
   another build counts as in use.
5. **Source.** Source only the gap. Whatever is left becomes a kit: the lines
   you are short of.
